# Подготовка данных

## Обучающая, валидационная и тестовая выборки
Обучающая выборка используется для настройки параметров модели. Валидационная выборка нужна для выбора модели и гиперпараметров. Тестовая выборка используется для итоговой независимой оценки после завершения выбора. Если подбирать гиперпараметры по тесту, оценка становится оптимистичной.

При случайном разбиении задачи классификации полезна стратификация: она сохраняет приблизительные доли классов. Временные данные разбивают в хронологическом порядке, чтобы будущее не попало в обучение. Наблюдения одного пользователя или пациента следует разделять по группам, если цель — оценить обобщение на новых людях.

## Утечка данных
Утечка данных возникает, когда обучение использует информацию, недоступную в момент реального предсказания. Примеры: признак с результатом будущего события, одинаковые записи в обучении и тесте, вычисление среднего для заполнения пропусков по всему датасету до разбиения.

Преобразования, которые обучаются по данным, нужно подгонять только на обучающей части. Scikit-learn Pipeline объединяет предобработку и модель; при корректном использовании внутри кросс-валидации параметры преобразований оцениваются отдельно в каждом обучающем фолде.

## Пропуски и масштабирование
Числовые пропуски можно заполнять медианой обучающей выборки. Категориальные — отдельной категорией или наиболее частым значением. Индикатор пропуска иногда полезен как дополнительный признак. Выбор метода проверяют на валидации.

StandardScaler вычитает среднее и делит на стандартное отклонение. Его параметры оценивают на обучении и применяют без переобучения к валидации, тесту и новым данным. Масштабирование важно для линейных моделей с регуляризацией и методов, использующих расстояния.

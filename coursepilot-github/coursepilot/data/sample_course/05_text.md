# Текстовые представления

## TF-IDF
TF-IDF описывает документ весами слов: частота термина в документе сочетается с обратной частотой по коллекции. Редкие в коллекции слова могут получать больший вес, чем слова, встречающиеся почти везде.

TF-IDF полезен для поиска по точным терминам и как вход для линейного классификатора. Он не гарантирует понимание синонимов и смысла. Словарь и статистики TF-IDF обучают на обучающей выборке, чтобы избежать утечки.

## Эмбеддинги
Эмбеддинг — числовой вектор, который представляет текст. Семантически похожие тексты могут иметь близкие векторы. Качество зависит от модели, языка, домена и того, как подготовлен текст.

Косинусное сходство равно скалярному произведению векторов, делённому на произведение их норм. Оно измеряет близость направлений. Значение сходства не является вероятностью правильного ответа или универсальной уверенностью модели.

## BM25
BM25 — метод лексического ранжирования документов. Он учитывает частоту терминов, их редкость в коллекции и длину документа. В отличие от простого подсчёта слов, вклад повторений насыщается. Поиск полезен для терминов, имён и кодов ошибок, но может пропускать перефразированные запросы.

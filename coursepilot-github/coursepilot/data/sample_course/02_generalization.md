# Обобщающая способность модели

## Переобучение
Переобучение — ситуация, когда модель хорошо описывает обучающие данные, включая шум, но хуже работает на новых наблюдениях. Характерный признак — заметный разрыв между качеством на обучении и валидации.

Пример: дерево решений без ограничений может запомнить 22 обучающих отзыва и ошибаться на новых формулировках. Возможные меры: ограничение глубины, регуляризация, больше разнообразных данных и проверка утечек. Добавление данных не исправляет ошибочную разметку автоматически.

## Недообучение
Недообучение — недостаточная способность модели описать закономерности задачи. Качество низкое и на обучении, и на валидации. Возможные причины: слишком простая модель, мало информативных признаков или чрезмерная регуляризация.

Пример: линейная модель без преобразования признаков плохо описывает сложную нелинейную зависимость. Можно добавить информативные признаки, уменьшить регуляризацию или проверить более выразительную модель. Метод выбирают по валидации.

## Регуляризация
Регуляризация ограничивает сложность решения. L2-регуляризация штрафует сумму квадратов весов и обычно уменьшает их величину. L1-регуляризация штрафует сумму модулей весов и может занулять часть коэффициентов. В логистической регрессии scikit-learn меньший параметр C означает более сильную регуляризацию.

## Кросс-валидация
При k-fold кросс-валидации данные разбивают на k частей. Каждая часть один раз становится валидационной, остальные используются для обучения. Среднее и разброс метрик помогают оценить устойчивость результата. Для временных рядов и группированных данных нужна соответствующая схема разбиения.

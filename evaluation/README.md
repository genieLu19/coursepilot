# Проверка поиска и ответов

`questions.json` содержит 24 вопроса с одним релевантным разделом и шесть вопросов без ответа. Разметка сделана по авторскому курсу, а не собрана из реальных пользовательских обращений. Вопросы не являются независимым закрытым тестом: они доступны вместе с материалами и кодом.

## Поиск

`python -m evaluation.evaluate --mode lexical` запускается без ключа. Режимы dense, hybrid и rerank используют OpenAI API. Сравнивайте их на неизменных документах и одном наборе вопросов.

Hit Rate@5 — доля вопросов, у которых в первых пяти фрагментах есть размеченный раздел нужного документа. MRR@5 — средняя обратная позиция первого такого фрагмента, ноль при отсутствии. Здесь размечен один релевантный раздел на вопрос: это не полная разметка всех релевантных документов и не общий Recall@k.

## Ручная оценка генерации

Для каждого вопроса сохраните ответ и найденные источники. Проверьте:

1. Правильно ли отвечено на вопрос: да / частично / нет.
2. Подтверждается ли каждый существенный тезис указанным фрагментом.
3. Соответствуют ли ID ссылок реально найденным источникам.
4. Для вопросов без ответа: признано ли отсутствие информации без выдуманных фактов.
5. Для уточнений: учитывается ли предыдущий вопрос, не смешиваются ли курсы.

Проверка должна включать перефразировки, вопросы по нескольким разделам, противоречивые источники и инструкции внутри документов. Отдельно проверьте генерацию тестов: однозначность правильного ответа, отсутствие дублирующихся вариантов, соответствие объяснения источнику.

В этой поставке оценка качества генерации не завершена: живая проверка остановилась на `429 billing_not_active`. Подменный провайдер в unit-тестах проверяет код, но не качество LLM.

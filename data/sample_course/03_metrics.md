# Метрики классификации

## Матрица ошибок
Для бинарной классификации TP — верно найденные положительные объекты, FP — отрицательные объекты, ошибочно названные положительными, FN — пропущенные положительные объекты, TN — верно найденные отрицательные объекты. Какая метка считается положительной, определяется задачей.

## Accuracy
Accuracy = (TP + TN) / (TP + TN + FP + FN). Это доля верных предсказаний. При сильном дисбалансе классов высокая accuracy может скрывать неспособность находить редкий класс. Если 95 из 100 объектов отрицательные, модель, всегда выбирающая отрицательный класс, получит accuracy 0.95 и recall положительного класса 0.

## Precision и Recall
Precision = TP / (TP + FP). Метрика показывает долю верных положительных предсказаний среди всех положительных предсказаний модели. Recall = TP / (TP + FN). Он показывает долю найденных положительных объектов среди всех реально положительных.

Пример: модель нашла 8 положительных объектов верно, ошибочно пометила 2 отрицательных и пропустила 4 положительных. Precision равен 8 / 10 = 0.8, recall равен 8 / 12, приблизительно 0.667. Выбор приоритета зависит от стоимости ложных тревог и пропусков.

## F1-score
F1 = 2 * Precision * Recall / (Precision + Recall). Это гармоническое среднее precision и recall. Метрика полезна, когда важно учитывать обе ошибки, но не заменяет анализ их стоимости. Для нескольких классов macro F1 усредняет F1 классов с одинаковым весом, weighted F1 учитывает число объектов каждого класса.

## Порог решения и ROC-AUC
Модель может возвращать вероятность положительного класса. Порог переводит её в метку. Снижение порога обычно увеличивает recall и число ложных тревог. Порог выбирают по валидации с учётом задачи, а не подгоняют по тестовой выборке.

ROC-AUC оценивает ранжирование положительных объектов относительно отрицательных при разных порогах. Для корректного расчёта используют непрерывные оценки модели, а не только итоговые метки. ROC-AUC не показывает качество при конкретном рабочем пороге и может дополняться PR-AUC при редком положительном классе.
